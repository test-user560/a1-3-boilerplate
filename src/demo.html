JavaScript로 화면 변경하기

JavaScript를 사용하면 사용자의 행동에 따라 HTML의 내용을 변경할 수 있습니다.

왼쪽 버튼을 클릭하면 JavaScript가 실행되고, 화면에 표시된 숫자가 1씩 증가합니다.

버튼 클릭 → JavaScript 실행 → HTML 변경

포켓몬을 골라보세요.

가져온 데이터를 보여주기

JavaScript는 서버에 있는 정보를 가져와 내 웹페이지에 보여줄 수 있습니다.

왼쪽에서 포켓몬을 고르면 이름과 이미지를 바로 가져옵니다.

옆의 사이렌 버튼을 누르면 오류가 났을 때의 화면도 확인할 수 있습니다.

fetch()는 서버에 정보를 요청할 때 사용하는 JavaScript 기능입니다.

포켓몬 선택 → 데이터 가져오기 → 화면에 보여주기
